# Shared glossary — use these exact Japanese forms

## Tone
ガイドブック調。簡潔で自然な日本語。直訳を避ける。
- 見出し・ラベル・スタット名: 体言止め（名詞句）。短く。
- 説明文・注意書き: です・ます調。
- タイムライン項目: 体言止めを基本とする（例「レンタカー受け取り」）。
- 英語の一人称複数（we / our）は日本語では原則省略する。

## Hard rules
1. HTML タグと文字実体参照はそのまま保持: `&middot;` `&yen;` `&mdash;` `&ndash;` `&rarr;` `&asymp;` `&deg;` `&amp;` `&times;` `<strong>` `<em>` `<small>` `<br>`
2. `<span class="u" data-metric="..." data-imperial="...">...</span>` は**属性も中身も一字一句変えない**。周囲の文だけ訳す。
3. 数字・時刻・価格・便名・座席番号・予約番号はそのまま。
4. 訳す必要がない文字列（`SNA 021`, `&yen;9,000`, `06:10 &rarr; 08:55` など）は英語のまま返す。
5. スマホの狭い1カラムに収まる長さにする。ボタン・タブ・スタット名は特に短く。
